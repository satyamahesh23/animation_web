# Satya Raw Pressery | Alphonso Mango Cold-Pressed Landing Web App

An interactive, responsive product landing page for **Satya Raw Pressery Alphonso Mango** cold-pressed juice featuring smooth scroll-driven 360° bottle spin, interactive sound effects, flavor switcher, and a custom basket/checkout drawer.

## 🌟 Features

- **360° Scroll-Driven Spin**: Uses 92 high-resolution sequence frames to render a smooth 360° bottle rotation as you scroll down the page.
- **Interactive "Drink Thumbs for Freshness!"**: Special interactive action button with custom Web Audio API sound synthesis, sparkling toast notifications, and confetti splash.
- **Mouse Parallax Physics**: Floating tropical mango leaves, juicy mango slices, and liquid splashes that move dynamically with mouse hover.
- **Interactive Basket & Checkout Drawer**: Real-time quantity adjustment, promo code calculator (`MANGO20`), and checkout modal.
- **Flavor Showcase**: Explore Alphonso Mango, Pink Guava Glow, and Valencia Orange.
- **Nutritional Facts & Benefits**: Transparent cold-pressed details and HPP preservation highlights.

## 🚀 Quick Start

1. Clone or download this repository.
2. Open `index.html` directly in any web browser, or serve it using any static HTTP server:
   ```bash
   npx http-server -p 8080
   ```
3. Visit `http://localhost:8080/index.html` in your browser.
